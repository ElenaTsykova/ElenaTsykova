### 🚀 Опыт

- 📊 **Производительность сотрудников**
создан дашборд,  который позволяет отслеживать производительность сотрудников в течение дня
Результат:
снизила ежедневные временные затраты руководителей на контроль задач на 40%
Стек: Luxms BI

- 🤖 **Оптимизация поиска технической документации**
актуальные инструкции и схемы были перенесены в тг бот по категориям
Результат:
сократила среднее время поиска инструкций с 30 до 3 минут, тем самым снизив и время простоя
Стек: aiogram, Python, VS Code

- 📈 **Автоматизация отчёта**
автоматизировала сбор данных из разных источников и расчёт показателей энергопотребления
Результат:
сэкономила час работы сотрудника ежедневно 
Стек: Airflow, Python
